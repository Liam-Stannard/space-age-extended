# The Core's production line

**Status:** two steps are built: crushing ore, and making plate. The rest is not
designed yet. It depends on how the game is won.

## 1. Crushing

The Drop Crusher turns 4 kamacite ore into 6 crushed kamacite and 2 kamacite
fines. It needs strong gravity, so it only works on the Core.

## 2. Plate

A furnace turns 3 crushed kamacite into 1 kamacite plate, and 4 kamacite fines
into 1 plate. Which furnace takes fines is still to be decided (TODO.md, "Decide
the Vacuum Furnace's job").
